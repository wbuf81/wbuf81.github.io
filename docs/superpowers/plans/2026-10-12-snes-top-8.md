# SNES Top 8 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `/videogames/snes-history/top-8`. Visitors build a MySpace-style SNES Top 8: search, drag to reorder, accept "friend request" recommendations, pick one of six themes, and save a 1080×1080 picture or a link that rebuilds it.

**Architecture:**
- **Pure logic:** recommendations, URL/state parsing, name cleaning and the slim game index live in `lib/snes/top8.ts`, with tests.
- **The picture:** drawn by a browser-only canvas renderer (`app/snes/top8/`) with one module per theme. The live preview and the saved PNG come from the same renderer.
- **The page:** a static server page hands the slim index to one client component (`Top8.tsx`) that owns state, dnd-kit sorting, search, requests, preview and save/share.

**Tech stack:** Next.js 16 static export, React 19, TypeScript, Jest + Testing Library, `@dnd-kit/core` + `@dnd-kit/sortable` (new, exact versions), `next/font/google` (Press Start 2P and Orbitron new), Python OG script.

**Spec:** `docs/superpowers/specs/2026-10-12-snes-top-8-design.md`. Approved prototype: https://claude.ai/artifact/LQAeVS1Uiuth7JgWwLSQpT. Its source is copied into this plan's SDD workspace as `prototype.html` and is the visual reference for every theme.

## Global Constraints

- **Route:** `/videogames/snes-history/top-8`. Add `TOP8 = \`${SNES_BASE}/top-8\`` to `lib/snes/routes.ts`. Static assets stay under `/snes/*`.
- **Search engines:** every new route has `robots: { index: false, follow: false }`.
- **`lib/snes/` code:**
  - `import type`, `.ts` relative imports, no `@/`, pure.
  - Tests import `@/lib/...` and `@/app/...`.
  - Fixtures are inline.
- **Colours:** tokens only. `app/snes/snes.css` forbids hex (`__tests__/snes-css.test.ts`). New tokens get dark twins in both dark blocks and are mirrored in `app/design/tokens.ts`. Canvas themes may use literal colours inside the theme modules, since the picture has its own fixed look.
- **Themes:** drawn entirely in code. No game logos, no ripped art, and no trademarked game names in theme labels. The labels are exactly MySpace Classic, Glitter, Console, Grand Prix, Crystal Menu and Polygon Space.
- **Picture:**
  - 1080×1080 PNG, file name `my-snes-top-8.png`.
  - Covers come from same-origin `/snes/box/<slug>.jpg`.
  - The 3×3 layout:
    - margin 22, gap 14
    - cell width `(1080 − 44 − 28) / 3`
    - cover height `round(cellW × 209/300)`
    - label band 40, centred vertically
    - cell 0 is the title tile; cells 1–8 hold the picks in order
- **Title text:** two lines, `"‹Name›'s"` or `"My"`, then `"Top 8"`. The display name is at most 24 characters; only letters, numbers, spaces and `'.-_&!` are kept.
- **State:**
  - **Shape:** `{ slots: (string|null)[8], theme: ThemeId, name: string, denied: string[] }`.
  - **URL:** `?g=` (comma-separated, `_` for an empty slot, at most 8, unknown slugs dropped, duplicates removed), `&skin=`, `&n=`.
  - **Storage:** key `snes-top8`, with every access wrapped in try/catch. URL parameters win over storage.
- **Recommendations:** deterministic, no randomness. Weights: similar +3, series +2, genre +1 (only adds to existing candidates unless fewer than 5 candidates exist, then only games scoring 8.0 or more), plus score/10 (EGM average, else aggregate/10, else users/10, else 6). Sort by score desc, then title asc. Top 5.
- **Payload:** page HTML plus RSC at most 120 KB gzipped, guarded by a jest test on the client props (gzip of the JSON at most 50 KB).
- **Fonts:** Press Start 2P and Orbitron (700, 900) via `next/font/google` with `display: 'swap'`, `preload: false` and fallbacks, loaded only by the Top 8 page. VT323 and IBM Plex Sans are reused.
- **Commits:** end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Work on branch `top-8`. Never push.

## Review Focus

1. **Duplicate and garbage input:** `?g=` with unknown, duplicate or 9+ slugs and `_`, plus a hostile or very long `n=` name, must sanitize without crashing or leaking markup into the canvas or DOM. Pinned in Task 1.
2. **A full Top 8 + Accept:** must enter replace mode, never silently drop or overwrite a game. Esc cancels. Pinned in Task 3.
3. **Canvas fonts:** the picture must be drawn after the theme's fonts load, or saved PNGs show fallback fonts (the prototype had this bug). Pinned in Task 2 (the renderer awaits `document.fonts.load` per theme) and checked by eye in Task 5.
4. **Phone drag vs scroll:** dragging a slot on a touch screen must not hijack page scroll; use a press delay (dnd-kit `TouchSensor` with `delay: 150, tolerance: 5`). Keyboard sorting must work. Pinned in Task 3 (keyboard) and Task 5 (touch, scripted).
5. **Blocked storage or clipboard, no Web Share:** everything still works. Pinned in Task 3.

```ts
import { EMPTY_STATE, STARTERS, cleanName, parseQuery, recommend, toQuery, type Top8Game, type Top8State } from '@/lib/snes/top8';

const G = (slug: string, o: Partial<Top8Game> = {}): Top8Game => ({ slug, title: slug.toUpperCase(), year: '1993', genres: [], series: null, similar: [], score: 7, ...o });
const games = [
  G('metroid', { genres: ['Platform', 'Adventure'], similar: ['castlevania', 'megaman'], score: 9.5 }),
  G('castlevania', { genres: ['Platform'], score: 8.5 }),
  G('megaman', { genres: ['Platform'], series: 'Mega Man', score: 8.8 }),
  G('megaman7', { genres: ['Platform'], series: 'Mega Man', score: 7.4 }),
  G('golf', { genres: ['Sport'], score: 9.0 }),
  G('puzzle', { genres: ['Puzzle'], score: 8.9 }),
  ...['super-mario-world', 'the-legend-of-zelda-a-link-to-the-past', 'super-metroid', 'chrono-trigger', 'donkey-kong-country', 'super-mario-kart'].map((s) => G(s)),
];
const st = (slots: (string | null)[], extra: Partial<Top8State> = {}): Top8State => ({ ...EMPTY_STATE, slots: [...slots, ...Array(8 - slots.length).fill(null)], ...extra });

describe('recommend', () => {
  it('suggests the starters when nothing is picked, skipping denied ones', () => {
    const r = recommend(st([], { denied: ['super-mario-world'] }), games);
    expect(r[0]).toEqual({ slug: 'the-legend-of-zelda-a-link-to-the-past', reason: 'a classic to start with' });
    expect(r.every((x) => STARTERS.includes(x.slug))).toBe(true);
  });
  it('weights similar over series over genre and explains the strongest signal', () => {
    const r = recommend(st(['metroid', 'megaman7']), games);
    expect(r[0]).toEqual({ slug: 'megaman', reason: 'because you picked METROID' }); // similar 3 + series 2 + genre 1 + 0.88
    expect(r[1]).toEqual({ slug: 'castlevania', reason: 'because you picked METROID' });
    expect(r.map((x) => x.slug)).not.toContain('metroid');
  });
  it('falls back to well-scored genre matches when there are too few candidates', () => {
    const r = recommend(st(['golf']), games);
    expect(r).toEqual([]); // no other Sport game scores 8.0+ in this fixture
    const r2 = recommend(st(['castlevania']), games);
    expect(r2.find((x) => x.slug === 'metroid')?.reason).toBe('you like platform games');
  });
  it('never suggests denied or picked games, and is deterministic', () => {
    const s = st(['metroid'], { denied: ['castlevania'] });
    expect(recommend(s, games).map((x) => x.slug)).not.toContain('castlevania');
    expect(recommend(s, games)).toEqual(recommend(s, games));
  });
});

describe('query', () => {
  const known = new Set(games.map((g) => g.slug));
  it('round-trips slots with empties, theme and name', () => {
    const s = st(['metroid', null, 'golf'], { theme: 'crystal', name: "Wes's pal" });
    const q = toQuery(s);
    expect(q).toBe("?g=metroid,_,golf,_,_,_,_,_&skin=crystal&n=Wes's%20pal");
    expect(parseQuery(q, known)).toEqual({ slots: s.slots, theme: 'crystal', name: "Wes's pal" });
  });
  it('drops unknown and duplicate slugs, keeps at most 8, ignores a bad skin', () => {
    const p = parseQuery('?g=metroid,nope,metroid,golf,a,b,c,d,e,f,g&skin=evil', known)!;
    expect(p.slots).toEqual(['metroid', 'golf', null, null, null, null, null, null]);
    expect(p.theme).toBeUndefined();
  });
  it('returns null when the query has none of its keys', () => {
    expect(parseQuery('?w=1994-04-18', known)).toBeNull();
  });
});

describe('cleanName', () => {
  it('keeps letters, numbers, spaces and a few marks, trims, caps at 24', () => {
    expect(cleanName('  <b>Wes</b> & Co!  ')).toBe('bWesb & Co!');
    expect(cleanName('x'.repeat(40))).toHaveLength(24);
    expect(cleanName('Zoë-Ann_9.')).toBe('Zoë-Ann_9.');
  });
});
```

- [ ] **Step 3: Implement `lib/snes/top8.ts`.**
  - **`slimIndex`:** reads `games.json` `Game` objects. Year = `releasedUS.slice(0, 4)`.
  - **`cleanName`:** NFC, then keep `[\p{L}\p{N} '.\-_&!]` (unicode flag), collapse spaces, trim, slice to 24.
  - **`parseQuery`:**
    - uses `URLSearchParams`
    - `g` split on `,`, at most 8 entries read before de-duplication
    - an unknown slug or a duplicate is removed and the remaining picks shift left
    - `_` is an empty slot
    - padded to 8 with null
    - `skin` is kept only when it's in `THEME_IDS`
    - `n` goes through `cleanName`
    - keys missing from the query are omitted from the result
  - **`toQuery`:** `encodeURIComponent` on the name. Keep `'` and `,` readable by encoding only what `encodeURIComponent` encodes, then replacing `%27` with `'`.
  - **`recommend`:** exactly per the Global Constraints. Reasons:
    - similar: `because you picked ${pick.title}`
    - series: `more ${series}`
    - genre: `you like ${genre.toLowerCase()} games`
    - starters: `a classic to start with`
    The strongest signal wins the reason; ties keep the first one assigned.

  - header "‹Name›'s Friend Space" or "My Friend Space" and `n of 8`

  - Sensors:
    - `PointerSensor` (`activationConstraint: { distance: 6 }`)
    - `TouchSensor` (`delay: 150, tolerance: 5`)
    - `KeyboardSensor` (`sortableKeyboardCoordinates`)
  - Screen-reader `announcements` in plain English: "Picked up Super Metroid, slot 1." "Super Metroid moved to slot 3." "Dropped Super Metroid in slot 3."

  - The header reads "You have N new friend request(s)!" or "No friend requests".
- **Preview box:**
  - A `<canvas width=1080 height=1080>` drawn with `drawTop8`, redrawn on state change through `requestAnimationFrame`, after `loadThemeFonts` and after the covers load (cache an `Image` per slug and redraw when each arrives).

    - **Save picture:** `canvas.toBlob` creates an object URL, clicks a temporary `<a download="my-snes-top-8.png">`, then revokes the URL.

    - **Copy link:** `navigator.clipboard.writeText(absoluteUrl)`, with a toast. On rejection, show a read-only selected input.
    - **Start over:** an inline confirm, then `EMPTY_STATE`, keeping the theme.
  - A toast region with `aria-live="polite"`.
- **State:**
  - Initial render uses `EMPTY_STATE` (server and client identical).
  - After mount: `parseQuery(location.search)` if present, else storage.
  - Every change saves to storage.
  - Once the visitor has edited, call `history.replaceState(null, '', toQuery(state))`.

A hero with an eyebrow link back to the library, the h1 "My SNES Top 8" and a one-line lede. `<main className={\`wb wb-page ${pressStart.variable} ${orbitron.variable} ${vt323.variable}\`}>`. `<SnesCredit />` at the foot (data line only).
