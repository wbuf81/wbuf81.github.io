# SNES media

Gameplay clips (12 seconds, re-encoded), title logos and 3D box renders come from Wes's personal scraped media library, matched to each game by its No-Intro name (`media-sources.json` lists the file used for every game). They belong to each game's publisher and are shown small and credited in a non-commercial history of the console. Box art credits: `box/SOURCES.md`.
